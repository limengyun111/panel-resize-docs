# Panel Resize Docs

## 简介

Panel Resize 是一个轻量级、高性能的拖拽面板组件，支持横向、纵向拖拽，提供灵活的配置选项。
Panel Resize Docs是对Panel Resize功能做了详细展示和讲解的文档栈，文档主要分为三个模块：
1. 场景板块
   演示了如何在真实项目中使用Panel Resize，以及如何从零实现一个Panel Resize
2. 案例板块
   展示了Panel Resize的主要功能和使用方式
3. 博客板块
   分享了一些技术文章用于学习和交流
